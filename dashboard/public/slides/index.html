Secure Sphere

Detect, divert, and learn from zero-day abuse before it reaches the real bank.

The problem

  • Static rules miss new abuse patterns.
  • Attack traffic still needs a safe, observable destination.
  • Defenders need a short path from first signal to first block.

Three verdicts

SAFE → real bank DIVERT → honeypot + learning DENY → blocked at gateway

Architecture

Gateway → bank or honeypot → Redis events → analyst learning loop → active rules → dashboard.

Every request has a correlation ID, verdict, OWASP mapping, and live feed entry.

OWASP coverage

Seven categories are demonstrated live. A03 supply chain, A04 cryptography, and A08 integrity are shown in prepared clips.

Live demo

Open the dashboard, click Run scenario, and watch the seven steps progress from normal traffic to the zero-day learning moment.

The scoreboard, totals, rules, timer, and honeypot console stay visible for judges.

Results

SAFE traffic remains green. Suspicious traffic is contained. Learned rules turn the next matching request into a DENY.
